Research Topic: Classification of Rock Songs into Subgenres Using Deep Learning Methods

Pre-processing: Converting 30 second mp3 clips of various genres into mel-spectograms, with one batch of normal data and one batch augmented using time shifting and masking.

Methods:
1. Basic Sequential CNN
2. DenseNet
3. Other classification methods (Logistic Regression, KNN, Support Vector Machine, XGBoost)
